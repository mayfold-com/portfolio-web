# Naim Chayata — Portfolio

A text-based personal portfolio built with SvelteKit and deployed to Cloudflare Workers.

## Developing

```sh
npm install
npm run dev
```

## Building & deploying

```sh
# Production build
npm run build

# Preview with Wrangler (Cloudflare runtime)
npm run preview

# Deploy to Cloudflare Workers
npm run deploy
```
